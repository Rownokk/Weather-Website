# 🌦️ Weather Website

A simple and elegant **Weather Website** made using only **HTML** and **CSS**.  
It displays sample weather information with a clean, responsive layout — perfect for beginners learning frontend design.

---

## ✨ Features

- 📱 Responsive Design (mobile-friendly)
- 🎨 Clean UI (simple and aesthetic)
- 💻 Pure HTML and CSS (no JS or APIs)
- 🌤️ Static demo weather display

---

## 🛠️ Technologies Used

- **HTML5** – structure  
- **CSS3** – styling & layout
